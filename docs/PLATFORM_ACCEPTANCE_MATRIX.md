## 验收规则

1. 登录窗口直接显示平台真实网页，登录完成后自动隐藏并保存会话。
2. 普通发布只创建一条作品，标题、正文、标签和素材均与输入一致。
3. 遇到短信、滑块或安全验证时显示同一真实浏览器窗口，完成后继续原任务。
4. 平台出现明确成功页或作品管理页可检索到作品后才记为 `published`。
5. 无法确认结果时必须记为 `publish_unknown`，由人工核对，不得自动重发。
6. 每个平台连续通过至少三轮后，才可把能力状态从 `beta` 调整为 `verified`。
